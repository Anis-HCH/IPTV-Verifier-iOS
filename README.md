# IPTV Verifier - iOS Optimized

📺 تطبيق فحص حسابات IPTV محسّن للأجهزة الذكية والـ iOS

## ✨ المميزات

✅ **فحص سريع للحسابات** - تحقق من حالة حسابات IPTV الخاصة بك
✅ **تصفية ذكية** - ابحث عن الفئات المفضلة لديك (BEIN, FR, UK, etc.)
✅ **محسّن للـ iOS** - يعمل بكفاءة على جميع أجهزة Apple
✅ **CORS Proxy متكامل** - حل مشاكل الأمان والوصول
✅ **حفظ البيانات محلي** - احفظ إعداداتك تلقائياً
✅ **تصدير سهل** - احفظ النتائج في ملف TXT
✅ **واجهة داكنة** - حماية العين في الليل
✅ **تطبيق ويب تقدمي (PWA)** - استخدمه كتطبيق حقيقي

## 🚀 البدء السريع

### الطريقة 1: عبر Safari على iOS
```
https://raw.githubusercontent.com/Anis-HCH/IPTV-Verifier-iOS/main/index.html
```

### الطريقة 2: تثبيت كـ تطبيق ويب (PWA)
1. افتح الرابط في Safari
2. اضغط على **Share** (الزر المشاركة)
3. اختر **Add to Home Screen**
4. اختر اسم التطبيق واضغط **Add**

### الطريقة 3: على جهاز الكمبيوتر
```bash
# استنسخ المستودع
git clone https://github.com/Anis-HCH/IPTV-Verifier-iOS.git
cd IPTV-Verifier-iOS

# شغّل خادم محلي
python3 -m http.server 8000

# افتح في المتصفح
http://localhost:8000
```

## 📖 الاستخدام

### إضافة الحسابات
1. الصق روابط Xtream (واحد في كل سطر):
   ```
   http://serveur1.com:80/get.php?username=user1&password=pass1
   http://serveur2.com:8000/get.php?username=user2&password=pass2
   ```

### تصفية الفئات
- اكتب الفئات المرغوبة مفصولة بفاصلة:
  ```
  BEIN, FR, UK, SPORT, ARABIC
  ```

### الإعدادات
- **Timeout**: الوقت المسموح لكل فحص (افتراضي: 15 ثانية)
- **CORS Proxy**: فعّل إذا واجهت أخطاء اتصال
  - Cloudflare Worker (موصى به)
  - CorsProxy.io
  - AllOrigins

### التصدير
- اضغط على **Exporter** لحفظ النتائج في ملف TXT
